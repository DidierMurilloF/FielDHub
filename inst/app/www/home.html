For teaching

A working example for every design in the syllabus.

FielDHub is used in courses on statistics, experimental design and plant breeding. Students see the randomization, the field layout and the data in one place.

install.packages("FielDHub")FielDHub::run_app()

Installs from CRAN and runs on the student's own computer.

  • Data to analyse from the first class

    Each design can simulate a response variable with the randomization, so there is a data set to fit a model to before anyone has a real trial.

  • Designs compared on the same entries

    Run the same entry list through an RCBD, an alpha lattice and a partially replicated design, and see how blocking and replication change the layout.

  • Exercises that reproduce

    Every design is an R function with a seed. A script or R Markdown assignment gives each student the same randomization, or a different one by changing the seed.
